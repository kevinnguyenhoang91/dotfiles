- **Shell:** Zsh

- **Plugins:** 35+ productivity and development plugins

## Terminal Emulator

- **Terminal:** Alacritty
- **Features:** GPU acceleration, ligature support
- **Theme:** Catppuccin Frappé

## Text Editor

- **Editor:** Neovim
- **Distribution:** LazyVim
- **AI Integration:** GitHub Copilot
- **Theme:** Catppuccin Frappé

## Terminal Multiplexer

- **Multiplexer:** tmux
- **Plugin Manager:** tpm (tmux plugin manager)
- **Status Bar:** Custom with git, battery, weather, pomodoro
- **Theme:** Catppuccin Frappé

## Package Management

- **Package Manager:** Homebrew
- **Configuration:** Brewfile for reproducible installations
- **Platform:** macOS and Linux support

## Configuration Management

- **Tool:** GNU Stow
- **Method:** Symlink-based dotfiles deployment
- **Structure:** Modular package organization

## Version Control

- **VCS:** Git
- **Visual Interface:** lazygit
- **Diff Viewer:** delta
- **Theme:** Catppuccin Frappé across all tools
